What a hash proves — and what it does not

A SHA-256 fingerprint is a 64-character summary of a file's exact bytes. If the file changes by even one bit, the fingerprint changes completely.

{{ ui.icon('check', 'icon icon-xs') }}
It shows: the file you hold now is identical to the file you fingerprinted earlier.
{{ ui.icon('x', 'icon icon-xs') }}
It does not show: that the content is authentic, that it was not edited before capture, or that an allegation is true. Integrity is not proof.
